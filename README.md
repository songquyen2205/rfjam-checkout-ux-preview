# RF Jam Checkout UX Preview

Standalone local preview of the proposed RF Jam ticket buyer flow. This is a visual prototype only; it does not connect to Hammer APIs, create orders, or process payments.

## View locally

Open `index.html` in a browser.

## Scope

- Ticket selection grouped by event day
- Attendee information and event acknowledgements
- Review step and simulated payment completion

Ticket names and prices are sample data for UX discussion and must be checked against the RF Jam workbook before use beyond this prototype.
